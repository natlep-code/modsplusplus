<h1 align="center">Mods++</h1>

Mods++ is a mod which, for the time being, only allows you to download third-party mods from a link pointing to a Geode mod ficee, Mods++ will provide a developer API.

# version

v1.0.0-alpha.1

# mod dependencies

<mod:geode.node-ids>

# setup :

open the mods++ Settings and setup by selecting the geode mod folder 
on android : 
```folder

/storage/emulated/0/Android/media/com.geode.launcher/game/geode/mods/

```

then

paste a link on url setting 

then go to menu of gd and click on the button with a arrow
